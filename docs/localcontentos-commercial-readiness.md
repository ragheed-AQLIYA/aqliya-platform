# Section 5: Regulatory Compliance — الامتثال التنظيمي

> LocalContentOS is designed to support Saudi organizations in meeting local content regulatory requirements. This section maps product capabilities to regulatory frameworks.

صُمم نظام المحتوى المحلي لدعم الجهات السعودية في تلبية متطلبات الامتثال للمحتوى المحلي.

## 5.1 Vision 2030 Alignment — التوافق مع رؤية 2030

| Vision 2030 Goal | LocalContentOS Contribution |
|------------------|-----------------------------|
| **Increase localization of spending** (هدف توطين الإنفاق) | Scoring engine measures local supplier spend ratio (35% weight). Tracks year-over-year localization trends. |
| **SME development and support** (دعم المنشآت الصغيرة والمتوسطة) | Supplier classification identifies SME spend. SPS-03 workbook line tracks SME procurement. |
| **Saudi workforce empowerment** (تمكين القوى العاملة السعودية) | Workforce localization metric (20% weight) tracks Saudi headcount and payroll ratios. |
| **Private sector contribution** (مساهمة القطاع الخاص) | Revenue localization metric (35% weight) measures local customer revenue. |
| **Sector diversification** (تنويع القطاعات) | Multi-project support across industries: technology, logistics, construction, healthcare, services. |
| **Ease of doing business** (تسهيل ممارسة الأعمال) | Governed digital workspace eliminates paper-based LC tracking. Automated scoring reduces manual effort. |
| **Transparency and governance** (الشفافية والحوكمة) | Full audit trail for every mutation. Evidence-linked classifications. Review and approval gates. |

## 5.2 NCAP Alignment — التوافق مع برنامج المحتوى المحلي

The **National Content and Private Sector Development Program (NCP)** or its regulatory arm:

| NCAP Requirement | LocalContentOS Capability |
|------------------|---------------------------|
| **Local content measurement** (قياس المحتوى المحلي) | LcScore engine with 4 weighted metrics (revenue 35%, supplier spend 35%, workforce 20%, assets 10%) |
| **Supplier registration with CR** | Mandatory CR number field in supplier registration. Locality classification (local/mixed/non-local). |
| **Spend classification** | Category-based spend records linked to suppliers. Local/foreign spend tracking. |
| **Evidence management** | Certificate, contract, invoice, attestation upload with storage backend and SHA-256 hash. Verification status tracking. |
| **Reporting and disclosure** | Bilingual PDF/XLSX exports with disclaimers. Audit trail for all reports. |
| **Annual compliance cycle** | Project-based workflow matching fiscal year reporting periods. |

## 5.3 Saudization / Nitaqat Alignment — التوافق مع السعودة / نطاقات

| Requirement | Mapping |
|-------------|---------|
| **Saudi workforce percentage tracking** | WRK-01 (نسبة القوى العاملة الوطنية) workbook line measures Saudization rate |
| **Payroll localization** | WRK-02 (نسبة رواتب السعوديين) tracks salary localization |
| **Wage Protection System (WPS)** | Data import compatible with WPS output formats |
| **Ministry of Human Resources reporting** | Workforce data exportable for HRDF / Ministry submissions |

## 5.4 Other Regulatory Frameworks — أطر تنظيمية أخرى

# Section 7: Case Study — دراسة حالة

## شركة الابتكار التقني — تقييم المحتوى المحلي FY2025  
### Al-Ibtikar Al-Taqni (Innovation Tech) — Local Content Assessment FY2025

> **Status:** Internal Pilot — Simulated Client Engagement  
> **Date:** FY2025–2026  
> **Products Used:** LocalContentOS (primary), AuditOS (supporting)  
> **Industry:** Technology / Digital Transformation (التحول الرقمي)

---

### 7.1 Background — الخلفية

**شركة الابتكار التقني** هي شركة تقنية سعودية تعمل في مجال التحول الرقمي وتقديم الحلول التقنية للقطاعين الحكومي والخاص. تواجه الشركة تحديات في:

- **إثبات المحتوى المحلي** للجهات الرقابية والمقاولات الحكومية
- **توثيق نسب التوطين** في المشتريات والعقود
- **إعداد تقارير دقيقة** للمحتوى المحلي وفق متطلبات هيئة المحتوى المحلي

> Al-Ibtikar Al-Taqni (Innovation Tech) is a Saudi technology company operating in digital transformation. The company faced challenges in proving local content compliance, documenting Saudization ratios, and preparing accurate local content reports.

### 7.2 Challenge — التحدي

| Challenge | Detail |
|-----------|---------|
| **Supplier data fragmented** | 45+ suppliers tracked across spreadsheets with no centralized system |
| **Local content unverified** | No evidence-backed classification for supplier locality |
| **Manual scoring** | Local content score calculated manually — error-prone and untraceable |
| **Reporting delays** | 7 days to produce a single local content report |
| **No audit trail** | Changes to supplier classifications undocumented |
| **Tender requirements** | Inability to demonstrate local content compliance for government contracts |

### 7.3 Solution — الحل

AQLIYA deployed LocalContentOS as a governed local content workspace with the following configuration:

#### Implementation — التنفيذ

| Phase | Activity | Duration |
|-------|----------|----------|
| **1. Onboarding** | Tenant setup, user provisioning (4 users: admin, operator, reviewer, viewer) | 3 days |
| **2. Data Import** | 45 suppliers registered with CR numbers, 25 spend records imported via CSV | 2 days |
| **3. Classification** | AI-assisted supplier classification with evidence upload (8 certificates, 3 contracts) | 1 day |
| **4. Scoring** | Complete workbook population, LcScore calculation (4 metrics) | 1 day |
| **5. Review** | Human review of classifications and scores, findings generation | 1 day |
| **6. Approval** | Official approval with audit trail | 1 day |
| **7. Export** | Bilingual PDF report + XLSX workbook with formulas | 30 minutes |

#### Key Configuration — التكوين الأساسي

| Parameter | Value |
|-----------|-------|
