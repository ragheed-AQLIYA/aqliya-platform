# سيناريو العرض التجريبي / Demo Flow Script

> Duration: 20 minutes | Audience: Institutional decision-makers
> المدة: 20 دقيقة | الجمهور: صانعو القرارات المؤسسية

---

## المقدمة / Overview

هذا السيناريو يعرض منصة AQLIYA في 6 فصول. كل فصل يركز على جانب مختلف من المنصة.

This script presents AQLIYA in 6 acts. Each act focuses on a different platform aspect.

---

## الفصل 1: المشكلة / Act 1: The Problem

**المدة / Duration:** 3 دقائق / 3 minutes

### الخطاب / Script

> "المؤسسات تعاني من تشتت الأنظمة، غياب الحوكمة، وصعوبة اتخاذ القرارات. كل نظام يعمل بمفرده، لا توجد أدلة، لا توجد مراجعة، لا توجد حوكمة."
>
> "Institutions suffer from system fragmentation, governance gaps, and decision-making difficulty. Every system operates in isolation — no evidence, no review, no governance."

### العرض / Show

- انتقل إلى `/auditos` — سطح العرض التجريبي
- Navigate to `/auditos` — the demo surface
- أظهر الفوضى: بيانات مبعثرة، لا حوكمة، لا سجلات
- Show the chaos: scattered data, no governance, no logs

### النقطة الرئيسية / Key Point

> "هذه هي المشاكل التي نحلها. AQLIYA هي الحل."
> "These are the problems we solve. AQLIYA is the solution."

---

## الفصل 2: المنصة / Act 2: The Platform

**المدة / Duration:** 5 دقائق / 5 minutes

### تسجيل الدخول / Login

- سجّل الدخول كـ `admin@aqliya.com` / `admin123`
- Login as `admin@aqliya.com` / `admin123`

### العرض / Show

1. **لوحة التحكم / Dashboard**
   - أظهر لوحة التحكم الرئيسية مع مقاييس المنتجات الـ 12
   - Show the main dashboard with 12 product metrics in one view
   - "كل شيء في مكان واحد. لا تشتت."
   - "Everything in one place. No fragmentation."

2. **شريط التنقل / Navigation Sidebar**
   - انتقل عبر المنتجات: AuditOS، DecisionOS، LocalContentOS، SalesOS، WorkflowOS
   - Navigate through products: AuditOS, DecisionOS, LocalContentOS, SalesOS, WorkflowOS
   - "منصة واحدة، منتجات متعددة، حوكمة مشتركة."
   - "One platform, multiple products, shared governance."

### النقطة الرئيسية / Key Point

> "AQLIYA ليست مجرد أداة. هي منصة مؤسسية كاملة."
> "AQLIYA is not just a tool. It is a complete institutional platform."

---

## الفصل 3: AuditOS — العمق / Act 3: AuditOS Deep Dive

**المدة / Duration:** 5 دقائق / 5 minutes

### العرض / Show

1. **إنشاء ملاحظة / Create a Finding**
   - Navigate to AuditOS workspace
   - أنشئ ملاحظة جديدة مع تصنيف وخطورة
   - Create a new finding with classification and severity

2. **إرفاق دليل / Upload Evidence**
   - ارفع ملفًا كدليل
   - Upload a file as evidence
   - "كل ملاحظة مدعومة بالدليل. لا مزاعم بدون أدلة."
   - "Every finding is evidence-backed. No claims without evidence."

3. **مراجعة واعتماد / Review & Approve**
   - أرسل الملاحظة للمراجعة
   - مراجعة من مراجع
   - اعتماد من مدير
   - " двойная مراجعة قبل أي قرار."
   - "Double review before any decision."

4. **تصدير / Export**
   - صدّر التقرير
   - Export the report
   - "التقرير يحتوي حالة، تعليق، طابع زمني، ومرجع للأدلة."
   - "The report contains status, disclaimer, timestamp, and evidence reference."

5. **سجل التدقيق / Audit Trail**
   - أظهر كل الإجراءات المسجلة
   - Show all logged actions
   - "كل إجراء مسجل. لا شيء مخفي."
   - "Every action is logged. Nothing is hidden."

### النقطة الرئيسية / Key Point

> "AuditOS ليست مجرد تدقيق. هي حوكمة مالية كاملة."
> "AuditOS is not just audit. It is complete financial governance."

---

## الفصل 4: حوكمة الذكاء الاصطناعي / Act 4: AI Governance

**المدة / Duration:** 3 دقائق / 3 minutes

### العرض / Show

1. **اقتراح ذكي / AI Suggestion**
   - أظهر اقتراحًا من الذكاء الاصطناعي
   - Show an AI-generated suggestion
   - "الذكاء الاصطناعي يقترح. الإنسان يقرر."
   - "AI suggests. Humans decide."

2. **مراجعة إنسانية / Human Review**
   - أظهر أن الاقتراح يحتاج مراجعة قبل التنفيذ
   - Show that the suggestion requires review before execution
   - "لا قرار آلي. كل شيء تحت المراجعة البشرية."
   - "No autonomous decision. Everything under human review."

3. **درجة الثقة / Confidence Score**
   - أظهر درجة ثقة الاقتراح (مثلاً 85%)
   - Show the suggestion's confidence score (e.g., 85%)
   - "درجة الثقة تساعد المراجع على الحكم."
   - "Confidence scores help reviewers judge."

### المبدأ / Principle

> **"AI assists. Humans decide. Evidence governes."**
> **"الذكاء الاصطناعي يساعد. الإنسان يقرر. الدليل يحكم."**

### النقطة الرئيسية / Key Point

> "AQLIYA تستخدم الذكاء الاصطناعي بأمان. لا قرارات آلية."
> "AQLIYA uses AI safely. No autonomous decisions."

---

## الفصل 5: الاستعداد المؤسسي / Act 5: Enterprise Readiness

**المدة / Duration:** 2 دقيقة / 2 minutes

### العرض / Show

1. **SSO / SAML**
   - أظهر إعدادات الدخول الموحد
   - Show SSO/SAML configuration
   - "تكامل مع أنظمة الدخول المؤسسية."
   - "Integration with enterprise authentication systems."

2. **صلاحيات حسب الدور / RBAC**
   - أظهر الفروقات بين الأدوار
   - Show differences between roles
   - "كل دور له صلاحيات واضحة ومحددة."
   - "Each role has clear, defined permissions."

3. **عزل البيانات / Data Isolation**
   - أظهر عزل بيانات المنظمات
   - Show organization data isolation
   - "بيانات كل منظمة معزولة تمامًا."
   - "Each organization's data is completely isolated."

4. **المراقبة / Monitoring**
   - انتقل إلى `/monitoring`
   - Navigate to `/monitoring`
   - "لوحة صحة المؤسسة. كل شيء تحت المراقبة."
   - "Enterprise health dashboard. Everything under monitoring."

### النقطة الرئيسية / Key Point

> "AQLIYA جاهزة للمؤسسات الكبيرة. أمان، حوكمة، و隔离."
> "AQLIYA is enterprise-ready. Security, governance, and isolation."

## الفصل 6: الأسئلة والأجوبة / Act 6: Q&A

**المدة / Duration:** 2 دقيقة / 2 minutes

| السؤال / Question | الإجابة / Answer |
|-------------------|-------------------|
| هل AQLIYA بديل للأنظمة الحالية؟ | AQLIYA تكمل الأنظمة الحالية وتضيف حوكمة |

### الإغلاق / Closing

> "AQLIYA هي منصة حوكمة مؤسسية. نبدأ ببيئة تجريبية. نثبت بالنتائج."
> "AQLIYA is an institutional governance platform. We start with a pilot. We prove with results."

## ملاحظات للمقدم / Notes for Presenter

### قبل العرض / Before the Demo
- تأكد من أن البيئة التجريبية تعمل
- Make sure the pilot environment is running
- تأكد من وجود بيانات تجريبية كافية
- Make sure there is enough demo data
- اختبر جميع الروابط قبل العرض
- Test all links before the demo

### أثناء العرض / During the Demo
- ركّز على الحوكمة والأدلة
- Focus on governance and evidence
- لا تتعمق في التفاصيل التقنية
- Don't go deep into technical details
- استخدم مثالاً واحداً كاملاً من البداية للنهاية
- Use one complete example from start to finish

### بعد العرض / After the Demo
- اجمع الملاحظات
- Collect feedback
- أرسل ملخصًا بالبريد الإلكتروني
- Send a summary via email
- حدد خطوة التالية
- Define the next step
