# AQLIYA Case Study: مؤسسة الابتكار التقني

**Status:** Simulated scenario for demonstration  
**Date:** 2026-06-30  
**Products Used:** AuditOS, LocalContentOS, DecisionOS, WorkflowOS

---

## الخلفية

مؤسسة الابتكار التقني— شركة تقنية سعودية تعمل في مجال التحول الرقمي. تواجه تحديات في توثيق المراجعة المالية، قياس المحتوى المحلي، وتوثيق القرارات الإدارية.

## التحدي

1. **المراجعة المالية:** توزع البيانات بين Excel والبريد الإلكتروني — لا يوجد مسار تدقيق موحد
2. **المحتوى المحلي:** صعوبة في إثبات نسب المحتوى المحلي للجهات الرقابية
3. **القرارات:** قرارات استراتيجية تُتخذ في اجتماعات بدون توثيق رسمي

## الحل

### AuditOS — مسار المراجعة
```
استيراد ميزان المراجعة (578 حساب)
  → تصنيف تلقائي للحسابات
  → كشف الدخل والميزانية
  → مراجعة واعتماد
  → تصدير PDF ثنائي اللغة
  → سجل تدقيق لكل خطوة
```

### LocalContentOS — المحتوى المحلي
```
تسجيل الموردين (45 مورداً)
  → تصنيف الإنفاق (80% محلي)
  → احتساب نسبة المحتوى المحلي
  → تقارير للجهات الرقابية
  → تصدير XLSX مع الصيغ
```

### DecisionOS — القرارات
```
توثيق 12 قراراً استراتيجياً
  → تحديد الخيارات والمخاطر
  → مراجعة اللجنة
  → اعتماد مع توقيع إلكتروني
  → أرشفة كاملة
```

## النتائج

| المقياس | قبل | بعد |
|---------|-----|------|
| وقت المراجعة | 3 أسابيع | 4 أيام |
| توثيق القرارات | 0% | 100% |
| تقارير المحتوى المحلي | 7 أيام | 30 دقيقة |
| سجل التدقيق | غير موجود | 450+ حدث |
| رضا الفريق | 40% | 92% |

## الدروس المستفادة

1. **البيانات النظيفة** هي مفتاح النجاح — استثمر الوقت في تنظيم البيانات قبل البدء
2. **اعتماد المستخدمين** يتم خلال 3 أيام عمل مع الدعم المناسب
3. **التقارير ثنائية اللغة** أساسية للجهات الرقابية في السعودية
4. **سجل التدقيق** يبني الثقة بين الإدارة والمراجعين

## الخطة القادمة

- ربط DecisionOS مع Institutional Memory لربط القرارات بالنتائج
- تفعيل AI Advisor لاقتراحات تحسين المحتوى المحلي
- توسعة WorkflowOS لإدارة الموافقات الداخلية
