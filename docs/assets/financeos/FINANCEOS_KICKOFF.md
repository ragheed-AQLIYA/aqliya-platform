## Program Basis

FinanceOS is the first product built under the **Institutional Engineering Standard (IES-001)**. All processes, templates, and governance requirements from the Standard are binding.

**No new architecture program. No baseline modification. No template redesign.**

## Required Sequence

The Standard mandates the following sequence for every product:

```text
Product Blueprint
        ↓
Capability Backlog
        ↓
PRD
        ↓
Domain Specification
        ↓
API Specification
        ↓
Workflow Specification
        ↓
UX Specification
        ↓
Test Specification
        ↓
ERR (Engineering Readiness Review)
        ↓
Implementation
        ↓
Architecture Drift Review (per WP)
```
