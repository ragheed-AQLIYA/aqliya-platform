# AQLIYA Pilot Guide

**適用對象:** Customer-facing team  
**Status:** Active | Version 1.0 | 2026-06-30

## Pilot Framework

AQLIYA pilots follow a structured 4-phase approach:
1. **Diagnostic** — Understand client needs
2. **Demo** — Guided walkthrough of relevant products
3. **Pilot** — Controlled execution with real data
4. **Deploy** — Scale to production
